# Skill Up

Skill Up é uma aplicação desenvolvida com Spring Boot para a criação e gerenciamento de projetos e portfólios, permitindo que profissionais e estudantes exibam seus trabalhos de forma organizada e colaborativa.


## 🚀 Tecnologias Utilizadas

- **Java**
- **Spring Boot**
- **PostgreSQL**
- **Maven**
- **Vercel**

## 📌 Funcionalidades

- Cadastro de usuários



## 🛠️ Como Executar o Projeto

### 1️⃣ Clonar o Repositório

```bash
git clone https://github.com/OpenIdeasTech/SkillUp_backend.git
cd skillup_backend
```

### 2️⃣ Instalar Java JDK 21

Faça o download do Java JDK 21 no site da [Oracle](https://www.oracle.com/br/java/technologies/downloads/) de acordo com o seu sistema operacional.

Verifique se o Java foi instalado corretamente:

```cmd
java -version
```

Configure as variáveis de ambiente do sistema, se necessário.

### 3️⃣ Configurar Variáveis de Ambiente do projeto

Crie um arquivo `.env` na raiz do projeto e configure as variáveis disponíveis no arquivo `.env.example`.

### 4️⃣ Rodar o Projeto

```
mvn spring-boot:run
```

A aplicação estará rodando na porta [8080](http://localhost:8080/swagger-ui.html).
